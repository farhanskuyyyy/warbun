# Warbun UI direction

Maintain the existing practical retail identity: Warbun wordmark, warm neutral background, deep red primary action, compact ledger/table layouts. No new imagery or invented metrics. Reading this as an operations workspace for shop staff and customers, ENERGY 1 / RHYTHM 1 / MOTION 1.

Use system sans for readable controls; deep red #8B1E2D marks the main action and current location; charcoal text supports long records. Use spacing to separate filters, records and totals. Receipts/references and labeled status rows repeat as the identity motif, grounded in transaction traceability. Customer catalog stacks on mobile; POS keeps products and cart together on desktop. Motion only indicates menu/control changes, with reduced-motion support. Reuse existing Tailwind components; no forced theme toggle or decorative assets.
