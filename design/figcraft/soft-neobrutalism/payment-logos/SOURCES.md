# Payment channel logo assets

Retrieved 30 October 2026 from the community-maintained idn-finlogos collection:
https://github.com/hafidznoor/idn-finlogos

Source files: https://raw.githubusercontent.com/hafidznoor/idn-finlogos/main/icons/{slug}.svg

Slugs: gopay, ovo, dana, bri, bca, mandiri, qris, visa, mastercard.

The downloaded SVG originals are retained here. PNG copies were rendered from the imported SVG vectors using Figcraft at 3x. Original brand colors/proportions are preserved on white plates in both themes. Channel names remain beside their logos. Logo usage identifies payment options in this design; it does not indicate an activated gateway or brand endorsement.

The same native design file now includes a source-vector assets page and logos on 92 channel rows across the existing payment prototype states. Mobile e-wallet, BRI and card previews were visually inspected; main payment PNGs and four theme PDFs were refreshed. No application or database changes.
